## 3. 语料边界

本项目的“工作语料”指全部 48 个本地受限 OCR 衍生 Markdown 文件，而不是仅指其中可直接抽取的正文条目。

这意味着当前源语料同时包含：

- 方剂正文条目
- 方剂异名或“见该条”类引导条目
- 卷首题名页、版权/CIP 信息页
- 编委会、前言等编纂说明性文字
- 目录、总目、索引类材料
- HTML 表格残留、图片占位、OCR 噪声

## 4. 当前已知混杂与缺陷

### 4.1 非条目内容混入

- 受限源文本的卷册起始区域包含题名页、CIP、版权、编委会、前言以及目录型 HTML 表格
- 部分尾段文件可见更重的尾部混杂、断裂和目录/索引式内容

### 4.2 正文条目噪声

- 正文条目总体存在稳定字段模式，但也可见
  - 条目直接粘连到下一条
  - `# 【用法】`、`# 【主治】` 之类误加 Markdown 标题
  - 条目内换行异常
  - 同一条内字段边界压扁

### 4.3 结构完整性

- 当前没有证据表明 9 册整体缺册
- 但尚未完成“物理册次 -> 数字分段文件”的一一对应清单
- 也尚未完成逐文件 checksum、页段来源和 OCR 批次登记

## 5. 当前工作假设

1. 全部 48 个本地受限源文件先作为原始源语料保留，不提前删除任何“脏页”。
2. 是否为可抽取正文，不由文件名决定，而由文档类型和条目资格规则决定。
3. 所有后续结构化、标注、benchmark 和论文表述，都以“源语料混杂且需分层处理”为前提。
