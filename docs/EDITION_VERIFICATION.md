# 《中医方剂大辞典》第2版版次核验

## 1. 结论

当前本地工作语料应按以下书目信息表述：

- 书名：《中医方剂大辞典》
- 版次：第 2 版
- 当前直接证据所在文件：[cidian/第9册.md](../cidian/第9册.md)
- 推荐论文写法：`基于《中医方剂大辞典》第2版构建……`
- 推荐年份写法：`2019 年第 2 版`

本项目当前不应写成“2022 年第 2 版”。
