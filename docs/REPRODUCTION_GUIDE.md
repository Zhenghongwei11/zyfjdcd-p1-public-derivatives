# Reproduction guide

## Public verification

The archived public package contains the data points underlying the reported tables and figures, public-safe benchmark labels and predictions, statistical outputs, and the author-generated analysis code. It excludes the copyrighted OCR-derived source text and phrase-level field values.

Run the public verification workflow from the repository root:

```bash
scripts/reproduce_one_click_public.sh
```

This command verifies the required package layout, recomputes inter-annotator agreement and held-out statistics, rebuilds the manuscript tables, and regenerates Figs 2–5 from the released derived data. It writes reconstructed outputs under `results/runs_public/<run_id>/`. Fig 1 is supplied as an editable SVG because it is a conceptual study-design diagram rather than a data-driven plot. The workflow does not reconstruct the copyrighted source text.

## Analysis environment

The core parser and integrity checks use the Python standard library. The supervised text baselines additionally require the packages listed in `requirements-analysis.txt`.

```bash
python3 -m pip install -r requirements-analysis.txt
```

The pretrained text baseline downloads `BAAI/bge-small-zh-v1.5` from its public model repository on first use. The model is used only to compute frozen text representations; the benchmark labels are not generated by the model.

## Re-running analyses with lawful source access

Researchers with lawful access to the 2nd edition source material may place the OCR-derived Markdown files in a local directory and run the parser without changing the public repository:

```bash
python3 scripts/bootstrap_formula_parser.py /path/to/local_markdown \
  --output-jsonl /path/to/private/formulas.jsonl \
  --summary-json /path/to/private/parse_summary.json
```

The resulting private JSONL can be passed to the released integrity-check, boundary-consensus, field-robustness, and evaluation scripts. Paths containing the OCR-derived text should remain outside public outputs.

## Reported-data reconstruction

The public per-record field-outcome table contains only identifiers, splits, document types, noise flags, binary presence/match indicators, and confusion-matrix outcomes. It contains no extracted field values. Aggregating `strict_outcome` by field and split reconstructs the field-robustness counts and metrics reported in the manuscript.

The public boundary-prediction table contains the test-set gold label and one prediction per model. It supports independent reconstruction of accuracy, precision, recall, F1, confidence intervals, and paired comparisons without access to the copyrighted text.

```bash
python3 scripts/recompute_boundary_baseline_statistics_v2.py \
  --predictions-tsv results/benchmarks/boundary_baseline_test_predictions_v2.tsv \
  --output-summary-tsv /tmp/boundary_summary.tsv \
  --output-comparisons-tsv /tmp/boundary_pairwise.tsv
```

## Versioning

Each public release that changes benchmark labels, model results, analysis code, or reported source data receives a new tagged release and Zenodo version DOI. The Zenodo concept DOI remains stable and resolves to the latest release.
