# 条目资格判定规则

## 1. 目标

定义什么内容可以进入条目切分、字段抽取、药名规范化和异名归并任务，避免后续只在“干净正文”上报分而人为抬高结果。

## 2. 总原则

1. 先判文档类型，再判任务资格。
2. 资格判断以片段或条目为单位，不以整文件为单位。
3. 无论是否进入主任务，困难片段都要有去向：排除、单独标记，或作为困难层保留。

## 3. 任务资格矩阵

| 文档类型 | 条目切分 | 字段抽取 | 药名规范化 | 异名归并 |
| --- | --- | --- | --- | --- |
| `FORMULA_ENTRY_FULL` | 是 | 是 | 是 | 是 |
| `FORMULA_ENTRY_NOISY` | 是 | 是，需可判边界 | 是，需能定位组成字段 | 是 |
| `FORMULA_ENTRY_REDIRECT` | 是 | 否 | 否 | 是 |
| `MIXED_UNKNOWN` | 仅人工复核后 | 否 | 否 | 仅人工复核后 |
| `FRONT_TITLE` / `BIB_RIGHTS` / `EDITORIAL_PARATEXT` | 否 | 否 | 否 | 否 |
| `TOC_INDEX` / `TABLE_HTML` / `IMAGE_PLACEHOLDER` | 否 | 否 | 否 | 否 |
| `OCR_NOISE` | 否，但可作噪声负样本 | 否 | 否 | 否 |

## 4. 什么算“可抽取条目”

一个片段可进入方剂条目相关任务，至少满足以下之一：

- 明确以 5 位编号开头，且后接方名或引导语
- 明确为某方异名条或“见该条”条
- 虽存在 OCR 问题，但人工可稳定划定条目边界

## 5. 什么不算“可抽取条目”

以下内容默认排除出条目抽取主任务：

- 题名页、出版社/CIP/版权信息
- 编委会、前言、修订说明
- 总目、目录、索引页
- HTML 表格目录
- 纯图片或图片占位
- 无法稳定解释为单一条目的 OCR 碎片

## 6. 特殊情况判定

### 6.1 异名引导条

示例模式：

- `为“某方”之异名。见该条。`

处理规则：

- 进入条目切分任务
- 进入异名归并任务
- 不进入常规字段抽取主评测

### 6.2 条目粘连

示例模式：

- 一个 `【主治】` 段尾直接接下一个 5 位编号

处理规则：

- 仍保留在条目切分和困难层字段抽取中
- 不允许静默删除
- 必须在错误切片中单独统计

### 6.3 误加 Markdown 标题

示例模式：

- `# 【用法】`
- `# 【主治】`

处理规则：

- 视为 OCR/格式噪声，不改变语义字段身份
- 原文保留，结构化层单独标准化

### 6.4 缺字段或字段顺序异常

处理规则：

- 若条目边界明确，仍可进条目切分
- 字段抽取时允许缺失字段
- 不因为缺某一字段而把整条排除

## 7. 评测与报告要求

后续 benchmark 报告至少要分开给出：

- 全体可评样本结果
- `FORMULA_ENTRY_NOISY` 困难层结果
- 非条目/负样本误报情况
- 被排除片段的数量与原因

## 8. 当前禁止做法

- 按文件名整体排除尾段文件
- 只保留“字段最全”的正文条目
- 在结果表中不披露排除比例
- 将 `FORMULA_ENTRY_REDIRECT` 误当作完整正文条目参与字段抽取评分
